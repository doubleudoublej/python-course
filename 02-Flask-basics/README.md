# Flask Basics (Weeks 4-7)

This folder contains the Flask workshop material and a sample to-do app.

Setup
1. Create (or activate) the venv (recommended per-folder):
```powershell
cd 02-Flask-basics
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Run the app (development)
```powershell
# Make sure within dir, if not already
cd 02-Flask-basics
.venv/Scripts/activate # To start virtual environment if not already
py app.py # For windows
python3 app.py # For Linux / Mac
```

To exit virtual environment
```powershell
deactivate
```
