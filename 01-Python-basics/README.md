# Python Basics (Weeks 1–3)

This folder contains exercises, examples and notes for the Python fundamentals track used in the workshop.

## What you'll find here
- Week01/ — beginner examples: variables, input, loops, conditionals, operations
- Week02-Eklavya/ — Dynamic typing, Data types, Variables (extra)
- Week03/ — functions, file handling, JSON, error handling, collections, notes

Examples & notable files
- Week01/comparison.py, conditional.py, loops.py, input.py, operations.py, variables.py  
- Week03/functions.py, file-handling.py, json-example.py, dictionary.py, list.py, tuple.py, error-handling.py  
- data.json, profile.json — sample data for I/O exercises  
- notes.txt — for file reading and file overwriting

## Setup (Windows PowerShell)
Open PowerShell and go to this folder:
```powershell
cd C:\Users\JJWDe\python-course\01-Python-basics
cd Week01 # For week 1; case sensitive
cd Week03 # For week 3; case sensitive
```

## Run examples
- Run a single script:
```powershell
# Be inside the folder of the script you want to run
cd Week01 # Example
py comparison.py # If you want to run comparison.py in week 1
```
